StemMaker macht ein Hobby-DJ aus der Schweiz, an vielen Abenden und dauerhaft kostenlos. Nächstes Ziel: ein Zertifikat zum Signieren, damit Windows beim ersten Start nicht mehr vor StemMaker warnt.

Download startet nicht? Hier klicken. Lieber ohne Installation? ZIP herunterladen.

Dein erster Start

  1. Setup startenÖffne StemMaker-Setup.exe. Adminrechte brauchst du keine.
  2. ZIP entpackenEntpacke StemMaker.zip in einen beliebigen Ordner und starte StemMaker.exe. Keine Installation nötig.
  3. Windows warnt?Zeigt Windows „Der Computer wurde durch Windows geschützt“, klick auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“.
  4. Musik hineinziehenDateien oder ganze Ordner, dann auf Start. Aus jedem Track wird Titel.stem.mp4 für Traktor und Mixxx.
