🐧 **Test version for Linux – please help testing!**

This is a **beta** of StemMaker for Linux: the regular Windows version running from a single AppImage with a built-in Wine. Nothing to install, not even Wine. Windows users: please keep using [StemMaker 2.2.1](https://github.com/Elospeed/StemMaker/releases/latest).

**How to test:** download the ZIP, unzip it and follow `Linux-Beta-Test-EN.md` (about 20–30 minutes). Feedback please in the [Discussions](https://github.com/Elospeed/StemMaker/discussions) or to elospeed.dev@gmail.com.

**New in beta2:** based on the final StemMaker 2.2.1. StemMaker detects Wine and runs Turbo on the CPU right away (no more failed graphics card test or fake GPU name), error lines of the Turbo pre-test are translated, StemPlayer 1.8.5 with smooth jog wheel and correct window size in the CD player view. Already in beta1: the window can be minimized, larger sound buffer against crackling.

**Known:** Turbo uses the CPU only on Linux (no graphics card yet); "Open folder" shows Wine's file manager.

🐧 **Testversion für Linux – Tester gesucht!**

Eine **Beta** von StemMaker für Linux: die normale Windows-Version in einer einzigen AppImage mit eingebautem Wine. Nichts zu installieren, auch kein Wine. Windows-Nutzer bleiben bitte bei [StemMaker 2.2.1](https://github.com/Elospeed/StemMaker/releases/latest).

**So testen:** ZIP herunterladen, entpacken und `Linux-Beta-Test-DE.md` folgen (etwa 20–30 Minuten). Rückmeldung gern in den [Diskussionen](https://github.com/Elospeed/StemMaker/discussions) oder an elospeed.dev@gmail.com.

**Neu in beta2:** auf Basis des fertigen StemMaker 2.2.1. StemMaker erkennt Wine und rechnet Turbo gleich auf der CPU (kein fehlschlagender Grafikkarten-Test und keine falsche Grafikkarte mehr), die Fehlerzeilen im Turbo-Vortest sind übersetzt, StemPlayer 1.8.5 mit glattem Jogwheel und richtiger Fenstergrösse in der CD-Player-Ansicht. Schon in beta1: das Fenster lässt sich minimieren, grösserer Tonpuffer gegen Knacksen.

**Bekannt:** Turbo rechnet unter Linux nur auf der CPU; „Ordner öffnen“ zeigt den Dateimanager von Wine.
