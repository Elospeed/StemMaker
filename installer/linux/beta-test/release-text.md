🐧 **Test version for Linux – please help testing!**

This is a **beta** of StemMaker for Linux: the regular Windows version running from a single AppImage with a built-in Wine. Nothing to install, not even Wine. Windows users: please keep using [StemMaker 2.2](https://github.com/Elospeed/StemMaker/releases/latest).

**How to test:** download the ZIP, unzip it and follow `Linux-Beta-Test-EN.md` (about 20–30 minutes). Feedback please in the [Discussions](https://github.com/Elospeed/StemMaker/discussions) or to elospeed.dev@gmail.com.

**New compared to the first Linux prototype:** the window can be minimized again, larger sound buffer against crackling.

**Known:** Turbo uses the CPU only on Linux (no graphics card yet); "Open folder" shows Wine's file manager.
