StemMaker für Linux (Beta) - Elospeed
=====================================

DE
Diese AppImage enthält die normale Windows-Version von StemMaker (mit
StemCLI, StemPlayer und StemTagger) und ein unverändertes Wine @WINE_VER@,
das sie unter Linux startet.

Start:   chmod +x StemMaker-*-x86_64.AppImage   und dann doppelklicken
Daten:   ~/.local/share/StemMaker-Wine/  (Einstellungen, Modelle, ffmpeg, Logs)
Beta:    Turbo rechnet unter Linux auf der CPU (Grafikkarte noch nicht).
         "Ordner öffnen" zeigt den Dateimanager von Wine.

EN
This AppImage contains the regular Windows version of StemMaker (with
StemCLI, StemPlayer and StemTagger) and an unmodified Wine @WINE_VER@ that
runs it on Linux.

Start:   chmod +x StemMaker-*-x86_64.AppImage   then double-click
Data:    ~/.local/share/StemMaker-Wine/  (settings, models, ffmpeg, logs)
Beta:    Turbo runs on the CPU on Linux (no graphics card yet).
         "Open folder" shows Wine's file manager.
