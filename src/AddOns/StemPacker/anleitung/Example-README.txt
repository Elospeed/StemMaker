Example for StemPacker (simple test tones, 5 seconds each, no real music)

  Downmix\   Song One (DOWNMIX #1).wav ...   = master files
  Channels\  Song One (A).wav ... (D).wav    = stems 1-4 (A, D stereo; B, C mono)

In StemPacker: preset "5.1 DVD", Master folder = Example\Downmix,
Stem 1 folder = Example\Channels (leave Stem 2-4 empty), "Find songs",
then "Pack all". The stem files appear next to the master files in Downmix\.
