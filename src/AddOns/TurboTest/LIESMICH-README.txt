StemMaker Turbo-Test
====================

DEUTSCH
-------
Dieser kleine Test misst, wie schnell StemMaker 2.0 (Turbo) auf deinem PC
Stems trennt, mit CPU und Grafikkarte. Es wird nichts installiert.

1. Das ganze ZIP in einen Ordner entpacken.
2. StemMaker-Turbo-Test.exe doppelklicken.
   (Warnt Windows SmartScreen: "Weitere Informationen" -> "Trotzdem ausführen".)
3. Warten (2 bis 10 Minuten). Der Test lädt einmal das Trenn-Modell (84 MB).
4. Am Ende "Per Mail senden" oder "Bericht kopieren" und den Bericht an
   elospeed.dev@gmail.com schicken.
5. Schliessen. Modell, Testmusik und Programm werden gelöscht.

Der Bericht enthält: Windows-Version, Prozessor, RAM, Grafikkarte mit
Treiber, die gemessenen Zeiten und die Auslastung. Keine persönlichen Daten.


ENGLISH
-------
This small test measures how fast StemMaker 2.0 (Turbo) separates stems on
your PC, using the CPU and the graphics card. Nothing is installed.

1. Extract the whole ZIP into a folder.
2. Double-click StemMaker-Turbo-Test.exe.
   (If Windows SmartScreen warns: "More info" -> "Run anyway".)
3. Wait (2 to 10 minutes). The test downloads the separation model once (84 MB).
4. At the end click "Send by e-mail" or "Copy report" and send the report to
   elospeed.dev@gmail.com.
5. Close. Model, test music and program are deleted.

The report contains: Windows version, processor, RAM, graphics card with
driver, the measured times and the load. No personal data.


ESPAÑOL
-------
Esta pequeña prueba mide lo rápido que StemMaker 2.0 (Turbo) separa stems en
tu PC, con la CPU y la tarjeta gráfica. No se instala nada.

1. Descomprime todo el ZIP en una carpeta.
2. Haz doble clic en StemMaker-Turbo-Test.exe.
   (Si Windows SmartScreen avisa: "Más información" -> "Ejecutar de todas formas".)
3. Espera (de 2 a 10 minutos). La prueba descarga una vez el modelo de separación (84 MB).
4. Al final pulsa "Enviar por correo" o "Copiar informe" y envía el informe a
   elospeed.dev@gmail.com.
5. Cierra. El modelo, la música de prueba y el programa se borran.

El informe contiene: versión de Windows, procesador, RAM, tarjeta gráfica con
controlador, los tiempos medidos y la carga. Ningún dato personal.
